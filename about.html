ℹ️ About This Project

Student Expense Tracker is a mini project made for the Front-End Web Technology (FWT) lab using HTML, CSS and JavaScript.

How to use

  1. Go to Add Expense and fill in the form.
  2. See all expenses on the My Expenses page and filter or delete them.
  3. Check the Summary page to see spending by category.

Technologies used

  • HTML - structure of the pages
  • CSS - colors, layout and dark mode
  • JavaScript - logic, validation and saving data in localStorage
